# DocVision-VLM

AI-powered Document Question Answering System built using FastAPI, PaddleOCR, Qwen2-VL, Qdrant, and Retrieval-Augmented Generation (RAG).

## Features

- Upload PDF documents
- Validate uploaded files
- Convert PDF pages into images
- Modular FastAPI backend
- UUID-based file storage

## Tech Stack

- Python
- FastAPI
- PyMuPDF
- Docker 
- PaddleOCR 
- Qdrant 
- Qwen2-VL
